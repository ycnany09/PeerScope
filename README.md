# 피어스코프 (PeerScope)

경쟁사(피어 그룹)의 재무를 한 화면에서 비교하는 웹앱입니다.


국내 기업은 금융감독원 전자공시시스템(DART), 미국 상장 기업은 미국 증권거래위원회(SEC) EDGAR의 공시 숫자를 자동으로 가져와
**수익성·성장성·안정성 지표, 최근 5년 추이, ROE 분해(듀폰 분석)** 를 자동으로 계산해 보여 줍니다.

## 왜 만들었나

경쟁사 재무 비교는 전략기획·경영분석 업무에서 자주 반복되는 작업입니다.
보통은 회사마다 공시를 열어 숫자를 옮겨 적고, 엑셀에서 비율을 다시 계산합니다.
이 과정을 자동화해서 **숫자를 모으는 시간은 줄이고, 해석하는 시간은 늘리는 것**이 목표입니다.

## 주요 기능

- **회사 검색**: 국내 상장사(DART)와 미국 상장 기업(SEC)을 섞어 최대 6곳까지 비교
- **원화/달러 표기 전환**: 금액을 원화 또는 달러로 바꿔 표시. 현재 환율 또는 연도별 환율(손익은 회계연도 평균, 재무상태는 결산일 환율) 선택
- **핵심 지표 카드**: 매출액, 영업이익률, 부채비율과 전년 대비 변화
- **비교표**: 매출 성장률, 영업이익률, 순이익률, 부채비율, 유동비율, ROE, ROA (지표별 1위 표시)
- **5개년 추이**: 사업보고서 두 개(기준연도, 2년 전)의 당기·전기·전전기 숫자로 5년을 채움
- **ROE 분해**: ROE = 순이익률 × 총자산회전율 × 재무레버리지
- **원본 데이터**: 사용한 DART 계정과 공시 원문 링크를 함께 표시해 숫자를 직접 확인 가능
- **엑셀 내려받기**: 비교표·5년 추이·원본 데이터를 한 파일로

## 계산 방식

| 지표 | 계산 |
|---|---|
| 매출 성장률 | (올해 매출 − 작년 매출) ÷ \|작년 매출\| |
| 영업이익률 | 영업이익 ÷ 매출액 |
| 순이익률 | 당기순이익 ÷ 매출액 |
| 부채비율 | 부채총계 ÷ 자본총계 (자본잠식이면 계산하지 않음) |
| 유동비율 | 유동자산 ÷ 유동부채 |
| ROE / ROA | 당기순이익 ÷ 자본총계 / 자산총계 (기말 값으로 단순 계산) |

- 계정은 DART 표준 계정 ID(`ifrs-full_Revenue` 등)로 먼저 찾고, 표준 ID를 쓰지 않는 회사는 계정 이름으로 찾습니다.
- 연결재무제표를 우선 사용하고, 없으면 개별재무제표로 대체합니다.
- 같은 연도의 숫자가 두 보고서에 모두 있으면 최근 보고서(정정이 반영된 값)를 사용합니다.
- 미국 기업은 XBRL 태그(`Revenues`, `OperatingIncomeLoss` 등)를 연도마다 후보 순서대로 찾고, 부채총계를 따로 공시하지 않으면 `부채와자본총계 − 자본총계`로 계산합니다. 회계연도는 결산일 기준이며 1~3월 결산은 직전 연도로 봅니다.
- 성장률과 비율은 각 회사의 보고 통화 그대로 계산하므로 환율의 영향을 받지 않습니다. 환율은 금액 표시에만 쓰입니다.

## 기술 구성

- **Python** — 데이터 수집·가공·계산
- **Streamlit** — 웹 화면
- **pandas / Plotly** — 표와 대화형 그래프
- **DART 오픈API** — `corpCode.xml`(회사 고유번호), `fnlttSinglAcntAll.json`(단일회사 전체 재무제표)
- **SEC EDGAR API** — `company_tickers.json`(티커 목록), `companyfacts`(XBRL 재무 수치)
- **Frankfurter API** — 유럽중앙은행 기준환율
- **pytest** — 가짜 DART 응답으로 계산 로직과 화면 전체를 자동 테스트
- **Pretendard** 글꼴 (SIL 오픈 폰트 라이선스, `static/` 폴더에 포함)

```
app.py            화면
static/           글꼴 파일
dart.py           DART 데이터 수집과 지표 계산 (화면과 분리)
sec.py            SEC EDGAR 데이터 수집
fx.py             환율
tests/            가짜 DART 응답과 자동 테스트
```

## 직접 실행하기

```bash
pip install -r requirements.txt
mkdir -p .streamlit && printf 'DART_API_KEY = "발급받은_키"\nSEC_USER_AGENT = "이름 이메일주소"\n' > .streamlit/secrets.toml
streamlit run app.py
```

인증키는 [DART 오픈API](https://opendart.fss.or.kr)에서 무료로 발급받을 수 있습니다.
SEC는 키가 필요 없지만 요청 헤더에 이름과 연락처 이메일을 넣도록 요구해서 `SEC_USER_AGENT`에 적습니다.
`secrets.toml`은 `.gitignore`에 포함되어 저장소에 올라가지 않습니다.

## 한계

- 사업보고서(연간) 기준이며 분기 실적은 다루지 않습니다.
- 은행·보험 등 금융업은 재무제표 구조가 달라 일부 지표가 계산되지 않을 수 있습니다.
- 국내(K-IFRS)와 미국(US GAAP)은 회계 기준이 달라 영업이익 등 일부 항목의 정의가 다를 수 있습니다.
- 유럽중앙은행 기준환율에 없는 통화(예: 대만 달러)로 보고하는 회사는 금액 변환이 되지 않고 비율만 비교됩니다.
- 업종과 회계 기준이 달라 숫자만으로 기업의 우열을 단정할 수는 없습니다.
